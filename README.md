# Agenda Operativa

Calendario di lavoro con turni, attività divise per urgenza (Urgente, Importante, Da organizzare, Informazioni), reparti, orario entro cui chiudere e sveglie.

- **Telefono (Android):** scarica `AgendaOperativa.apk` dall'ultima versione in *Releases* e installalo.
- **Computer:** apri la pagina GitHub Pages del repository.
- **Dati:** sincronizzati con Firebase; ogni utente vede solo i propri.

Ogni modifica al ramo `main` ricostruisce automaticamente app e sito.
